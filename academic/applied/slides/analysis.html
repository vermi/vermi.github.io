Follow-Up Discussion

1. How confident are you in each answer—and why might it be misleading?

File hash (High), filename (Low), first-seen (Medium), domains (Low-Medium), IP:PORT (Medium), MITRE ID (Medium-High), DLL (Low-Medium). This separates solid IOCs from noisy ones.

2. If you could only take two actions right now, what would you do—and what’s the tradeoff?

Add the hash to a deny list (low collateral damage). Watch/alert on connections to the suspicious IP:PORT (safer than blocking all of Facebook). This builds prioritization instincts and avoids self-inflicted outages.

3. Connect each IOC to a basic Sec+ control and the “so what?”
