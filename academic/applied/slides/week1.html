The CIA Triad: Core Cybersecurity Objectives

🔒 Confidentiality

Ensures unauthorized individuals cannot access sensitive information.

Controls: Firewalls, ACLs, Encryption

✅ Integrity

Prevents unauthorized modifications to information or systems.

Controls: Hashing, Integrity Monitoring

🌐 Availability

Ensures systems are accessible when legitimate users need them.

Controls: Fault Tolerance, Clustering, Backups

Exam Note: Remember that Nonrepudiation is also important - it means someone cannot deny taking an action (e.g., digital signatures).

The CIA Triad: What It Means to YOU

🔒 Confidentiality Failures You Know

  • Snapchat (2014): 4.6 million usernames and phone numbers leaked.
  • LinkedIn (2021): 700 million user profiles scraped and sold.
  • Your University: What if your grades, financial aid info, or private messages were posted online?

✅ Integrity Attacks

  • Grade Changes: Students hacking systems to change grades (happens more than you think!).
  • Social Media: Someone posts fake content from your account.
  • Online Banking: Transactions mysteriously appearing/disappearing.

🌐 Availability Problems

  • Instagram/WhatsApp Outage (2021): 6+ hours offline - social media panic!
  • College Registration Systems: Crashing right when course registration opens.
  • Gaming: PSN, Xbox Live, Steam going down during major releases.

The DAD Triad: Key Cybersecurity Threats

💥 Disclosure

Exposure of sensitive information to unauthorized individuals.

Violates: Confidentiality

Example: Data exfiltration

🔧 Alteration

Unauthorized modification of information.

Violates: Integrity

Example: Fraudulent transactions

🚫 Denial

Disruption of authorized user access to information.

Violates: Availability

Example: DDoS attacks

Security Breach Impact Categories

💰 Financial Risk

Direct: Incident response costs, infrastructure rebuilding. Indirect: Lost revenue, competitive disadvantage.

📰 Reputational Risk

Loss of goodwill among customers, employees, suppliers, and stakeholders due to negative publicity.

🎯 Strategic Risk

Reduced effectiveness in meeting major goals and objectives, potential loss of competitive advantage.

⚙️ Operational Risk

Impact on day-to-day functions, process delays, manual workarounds.

📋 Compliance Risk

Violations of legal/regulatory requirements (e.g., HIPAA sanctions).

Case Study: Equifax Breach (2017)

🚨 The Disaster: 147 Million People's Data Stolen

Social Security numbers, birth dates, addresses, driver's licenses, credit cards...

Cause: Unpatched web application vulnerability (they knew about it for months!)

💰 Financial: $1.4 BILLION in costs (settlements, fines, IT improvements).
📰 Reputational: Company became a laughingstock, CEO resigned, stock crashed.
🎯 Strategic: Lost competitive position, customers fled.
⚙️ Operational: Massive IT infrastructure overhaul required.
📋 Compliance: $575 million settlement with government agencies.

Security Control Categories

💻 Technical Controls

Enforce security in the digital space.

Examples: Firewalls, IPS, Encryption, ACLs

⚙️ Operational Controls

Processes for secure technology management.

Examples: User access reviews, Log monitoring, Vulnerability management

📊 Managerial Controls

Procedural risk management mechanisms.

Examples: Risk assessments, Security planning, Change management

🏢 Physical Controls

Security controls in the physical world.

Examples: Fences, Locks, Fire suppression, Burglar alarms

Security Control Types

🛡️ Preventive Controls

Stop security issues before they occur (e.g., Firewalls, Encryption).

⚠️ Deterrent Controls

Discourage attackers from attempting violations (e.g., Guard dogs, Barbed wire).

🔍 Detective Controls

Identify security events that have occurred (e.g., Intrusion Detection Systems).

🔧 Corrective Controls

Remediate security issues after they occur (e.g., Restore backups after ransomware).

⚖️ Compensating Controls

Mitigate risk when original controls cannot be implemented.

📝 Directive Controls

Inform what should be done to achieve security objectives (e.g., Policies, Procedures).

Data Protection: Three Data States

📁 Data at Rest

Stored on hard drives, tapes, cloud, or other storage media.

Risk: Theft by insiders or external attackers

🌐 Data in Transit

Data moving over networks.

Risk: Eavesdropping on untrusted networks

💻 Data in Use

Data actively being processed in memory.

Risk: Memory content theft by system attackers

Key Point: Different security controls are needed to protect data in each of these states.

Data Minimization and Obfuscation

Data Minimization Goal

Reduce risk by reducing the amount of sensitive information maintained. Best approach: destroy data when no longer needed.

🔗 Hashing

Transform values using hash functions.

Risk: Rainbow table attacks

🎫 Tokenization

Replace sensitive values with unique identifiers using lookup tables.

Note: Keep lookup table secure!

🎭 Masking

Replace characters with X's or *'s.

Example: XXXX-XXXX-XXXX-1234

Data Obfuscation: You See It Everywhere!

🎭 Masking Examples You Use Daily

  • Credit Cards: Online shopping shows ****-****-****-1234
  • Bank Apps: Account numbers show ***************7890
  • Email: Password reset sent to j***e@gmail.com
  • Student Portal: SSN displayed as ***-**-5678

🎫 Tokenization in Action

  • Apple Pay/Google Pay: Your real card number never leaves your phone.
  • Student ID Numbers: Random numbers instead of SSN (older systems used to do this!).
  • Online Gaming: Player IDs instead of real names in tournaments.

🔗 Hashing Reality Check

Bad Example: Website stores password as hash of "password123".

Problem: Attacker tries common passwords, finds match.

Better: Add "salt" (random data) before hashing.
