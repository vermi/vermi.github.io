Midterm Exam Review

Exam Structure

Section 1: Scenario Analysis & Controls

You will be given a short scenario (e.g., a small business network) and asked to identify threats and propose appropriate technical and operational security controls.

Section 2: Cryptography Concepts

You will need to provide a comprehensive comparison of symmetric and asymmetric encryption, covering keys, advantages, disadvantages, and real-world use cases.

Section 3: Security Assessment Methodologies

You will need to explain the differences between vulnerability scanning and penetration testing, describe when to use each, and name common tools.

Review: Scenario Analysis & Controls

How to Identify Threats

Look for weaknesses in any domain. Ask yourself "what could go wrong here?" Think about categories like:
• Physical: Unlocked doors, accessible servers.
• Network: Guest Wi-Fi on the same network as sensitive data.
• Human: Employees susceptible to phishing.
• Software: Unpatched systems, malware.

How to Propose Controls

Match a control to a threat:
• Technical Controls are implemented in technology (e.g., Firewall to segregate networks, Full Disk Encryption to protect stolen data).
• Operational Controls are procedures and processes executed by people (e.g., Security Awareness Training to combat phishing, policy requiring background checks).

B) Creating a separate, isolated network (VLAN) for the POS terminal.
C) Placing a lock on the back-office door.
D) Running a weekly vulnerability scan.

Review: Cryptography Concepts

Symmetric Encryption

  • Keys: Uses a single, shared secret key for both encryption and decryption.
  • Advantage: Very fast and efficient, suitable for large amounts of data (bulk encryption).
  • Disadvantage: Secure key exchange is a major challenge. How do you get the key to the other person without an attacker intercepting it?
  • Use Case: Encrypting a hard drive (Full Disk Encryption) or a large file with AES.

Asymmetric Encryption

  • Keys: Uses a key pair: a public key (shared with everyone) and a private key (kept secret).
  • Advantage: Solves the key exchange problem. Anyone can use your public key to send you a secure message.
  • Disadvantage: Much slower and more computationally expensive than symmetric encryption.
  • Use Case: Establishing a secure web session (TLS/SSL) or creating digital signatures.

Knowledge Check: Cryptography

C) First with your private key, then with the recipient's public key.
D) First with your public key, then with the recipient's private key.

Review: Security Assessment Methodologies

Vulnerability Scan

An automated, passive process that scans systems for known vulnerabilities (e.g., missing patches, misconfigurations). It produces a report of potential issues. It is broad but not deep.

Penetration Test

An active, authorized hacking attempt that tries to exploit vulnerabilities to determine the actual risk and impact. It is narrow but very deep.

When to Scan vs. Pen Test

A vulnerability scan is the appropriate first step to get a baseline understanding of an organization's security posture. It's used for routine checks and patch management verification. A penetration test is a more mature, targeted assessment performed after basic security hygiene has been established.
