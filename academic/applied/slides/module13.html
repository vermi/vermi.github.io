Wireless Connection Methods

Cellular

  • 4G LTE and 5G networks
  • Managed by carrier, not organization
  • Treat as external network

Wi-Fi

  • 2.4 GHz and 5 GHz bands
  • 802.11n/ac/ax (Wi-Fi 4/5/6)
  • Extends beyond physical boundaries

Bluetooth

  • Short-range (5-30 meters)
  • Point-to-point connections
  • Pairing with PIN validation

RFID

  • Active or passive tags
  • Used for access control, inventory
  • Vulnerable to cloning attacks

GPS and Geolocation

GPS Purpose:

Satellite-based positioning system providing location accuracy within a foot. Not a network for device transmission.

GPS Capabilities

  • Highly accurate positioning for geofencing
  • Provides consistent time signal
  • Can be jammed or spoofed (uncommon)
  • Used for location-aware authentication

Geolocation

  • Combines GPS, Wi-Fi, Bluetooth, cellular
  • Rich data about device location
  • Used by Find My and similar services
  • Enables location-based access controls

Wireless Network Models

Point-to-Point

  • Connects two nodes directly
  • Transmissions only received by endpoints
  • Used for dedicated links

Point-to-Multipoint

  • Single source to multiple receivers
  • Wi-Fi is a common example
  • Many nodes receive transmitted data

Mesh

  • Devices connect to multiple peers
  • Self-healing network topology
  • Redundant paths for reliability

Broadcast

  • Information sent to many nodes
  • No response expected
  • GPS and radio are examples

Evil Twins and Rogue Access Points

Evil Twin Attacks

  • Malicious AP mimicking legitimate network
  • Positioned closer or with stronger signal
  • Captures victim network traffic
  • Often provides Internet to avoid detection
  • Can present fake login pages for credential theft

Rogue Access Points

  • APs added to network intentionally or unintentionally
  • Create unauthorized entry points to network
  • Can be devices with built-in wireless capabilities
  • Detection via wireless controllers and WIDS
  • Monitor for unknown APs in coverage area

Bluetooth Attacks

Bluejacking

  • Sends unsolicited messages
  • To Bluetooth-enabled devices
  • Generally low impact

Bluesnarfing

  • Unauthorized access to device
  • Gathers contact lists, data
  • Exploits weak pairing

Security Weaknesses

  • Designed for ease of use (easy to attack)
  • Fixed PINs reduce security (e.g., 0000)
  • Vulnerable to eavesdropping and BIAs

Best Practice: Turn off when not in use, change default PINs, patch regularly

RF and Protocol Attacks

Disassociation Attacks

  • Forces device to disconnect from AP
  • Sends spoofed deauthentication frames
  • Creates opportunity for evil twin attacks
  • WPA2 management frames often unencrypted
  • WPA3 requires protected management frames

Jamming

  • Blocks all traffic in frequency range
  • Essentially wireless interference
  • Can be intentional or unintentional
  • Illegal in the United States (FCC regulations)
  • Different from deauthers (protocol vs. power)

Mobile Device Vulnerabilities

Sideloading

  • Transferring files via USB, SD card, or Bluetooth
  • Installs apps outside official app store
  • More common on Android devices
  • Can bypass app signing requirements
  • Often prohibited by organizational security policies

Jailbreaking

  • Exploits vulnerabilities to gain root access
  • Conducts privilege escalation attack
  • Allows installation of unauthorized apps
  • Changes settings not normally available
  • Bypasses native security model
  • Can be detected by MDM tools

Network Design: Site Surveys

Purpose:

Understand the physical environment and existing wireless networks before deployment

Site Survey Process

  • Physical walkthrough of entire facility
  • Identify existing networks and APs
  • Map signal strengths throughout space
  • Use GPS and physical marking for location
  • Consider building materials and obstacles

Heatmaps

  • Visual representation of signal strength
  • Shows coverage areas and dead zones
  • Identifies channel overlap and interference
  • Helps optimize AP placement
  • Prevents signal extending beyond premises

Wi-Fi Channel Planning

2.4 GHz Band Challenges

  • 11 channels in North America (1-11)
  • Each channel is 20 MHz wide with 5 MHz spacing
  • Channels overlap in 70 MHz allocation
  • Only channels 1, 6, and 11 don't overlap
  • Must coordinate channel usage to avoid interference

Best Practices

  • Use non-overlapping channels (1, 6, 11)
  • Overlay channel usage on heatmaps
  • Enable automatic channel selection on APs
  • Use WLAN controllers for dynamic adjustment
  • Monitor for interference and rogue devices

Controller and Access Point Security

WLAN Controllers

  • Centralized management of access points
  • Software-defined wireless capabilities
  • Can be hardware, cloud, or VM-based
  • Provide monitoring and intelligence
  • Enable Wi-Fi and 5G roaming

Securing Controllers and APs

  • Change default settings and passwords
  • Disable insecure protocols and services
  • Place on isolated VLANs or management networks
  • Regular patching and firmware updates
  • Enable logging and monitoring
  • Configure threat intelligence and IPS features

WPA2 Security Standard

WPA2-Personal (PSK)

  • Pre-shared key authentication
  • No authentication server needed
  • Same password for all users
  • Easier to deploy, less secure

WPA2-Enterprise

  • RADIUS authentication server
  • 802.1X implementation
  • Unique credentials per user
  • Individual identification

CCMP Encryption

  • Counter Mode CBC-MAC Protocol
  • Uses AES encryption for confidentiality
  • User authentication and access control
  • Much stronger than legacy WEP
  • Note: Network authentication not included (added in WPA3)

WPA3 Security Standard

Required since mid-2020

All Wi-Fi devices must support WPA3 for certification

WPA3-Personal Improvements

  • SAE: Simultaneous Authentication of Equals
  • Replaces pre-shared keys with mutual validation
  • Slows down brute-force attacks
  • Perfect Forward Secrecy: Protects past traffic
  • Traffic secure even if password compromised

WPA3-Enterprise Improvements

  • Optional 192-bit security mode
  • Authenticated encryption
  • Enhanced key derivation and authentication
  • Improved protection for network frames

Wireless Authentication Methods

Open Networks

  • No authentication required
  • Often use captive portals
  • No encryption provided
  • Traffic at risk

Pre-Shared Keys

  • Shared passphrase
  • Provides encryption
  • No individual identification
  • Easy deployment

Enterprise

  • RADIUS server
  • EAP authentication
  • Unique credentials
  • Individual tracking

802.1X Standard

  • IEEE standard for port-based access control
  • Used for both wired and wireless
  • Integrates with RADIUS servers
  • Enables enterprise authentication
  • Can trigger actions based on user attributes

Extensible Authentication Protocol (EAP)

PEAP

  • Server cert authentication
  • Wraps EAP in TLS tunnel
  • Unique keys per device

EAP-TLS

  • Certificate-based (both sides)
  • Most secure option
  • Cert management overhead

EAP-TTLS

  • Extends EAP-TLS
  • No client certificate required
  • Similar to PEAP

EAP-FAST

  • Cisco proprietary
  • Faster roaming
  • Uses symmetric keys

Mobile Device Deployment Models

BYOD

Bring Your Own Device

  • User owns and manages device
  • Lower cost to organization
  • Greater user freedom
  • Less organizational control
  • Higher security risk

CYOD

Choose Your Own Device

  • Organization owns device
  • User selects from options
  • Easier support (limited models)
  • Better security than BYOD

COPE

Corporate-Owned, Personally Enabled

  • Company owns and manages device
  • Allows reasonable personal use
  • Balances security and user satisfaction
  • Users unlikely to carry two phones

Mobile Device Management (MDM)

Purpose:

Centralized management and security for mobile devices across deployment models

MDM vs UEM

  • MDM: Mobile-specific management
  • Phones, tablets, mobile OS
  • UEM: Unified endpoint management
  • Mobile + desktop + laptops

Key Challenges

  • OS limitations and variability
  • Hardware manufacturer differences
  • Carrier settings and versions
  • Diverse deployment models

MDM Features (Part 1)

Application Management

  • Deploy and control apps remotely
  • Limit installation permissions
  • Monitor usage

Content Management (MCM)

  • Secure organizational files
  • Separates business and personal data
  • Controlled access to content

Remote Wipe

  • Full or selective wipe options
  • For lost/stolen devices
  • Requires device connectivity

MDM Features (Part 2)

Geofencing

  • Restrict usage by location
  • Auto-wipe if leaves area
  • Locate lost devices

Authentication

  • Screen locks and timeouts
  • Password/PIN policies
  • Biometric & context-aware

Containerization

  • Separate work/personal contexts
  • Secure containers/wrappers
  • Prevents cross-contamination

Full Device Encryption

  • Best protection when lost/stolen
  • Combine with remote wipe
  • Prevents data breaches

MDM Device Controls

Hardware Controls

  • Camera/microphone blocking
  • USB and external media
  • GPS tagging controls

Communication

  • SMS/MMS restrictions
  • Wi-Fi/Bluetooth/NFC controls
  • Disable tethering

Software Controls

  • Detect jailbreaking and rooting
  • Monitor firmware and OTA updates
  • App allow/block lists and prevent sideloading

Hardening Mobile Devices

CIS Benchmarks

  • iOS and Android hardening guidelines
  • Industry-standard security practices
  • Regularly updated for new OS versions

Essential Hardening Steps

  • Update and patch OS regularly
  • Enable remote wipe and full-device encryption
  • Require strong passcodes with screen locks
  • Wipe after excessive passcode failures
  • Turn off unused connectivity

Think-Pair-Share Activity

Mobile Device Deployment Scenario

Your organization is expanding its workforce to include 200 remote employees who need access to sensitive customer data and internal applications. You need to decide on a mobile device deployment model and security controls.

  • Budget constraints limit device spending
  • Must comply with data protection regulations
  • Employees prefer flexibility in device choice
  • Need to support iOS and Android

Think (2 minutes):

Which deployment model would you choose (BYOD, CYOD, COPE)? What MDM features are essential?

Pair (3 minutes):

Discuss your choices with a partner. Compare trade-offs between security, cost, and user satisfaction.

Share (5 minutes):

Share your recommended solution with the class.

Key Takeaways

Wireless Security Fundamentals

  • Multiple wireless technologies serve different purposes
  • Site surveys and heatmaps guide secure network design
  • WPA3 provides significant security improvements over WPA2
  • Enterprise authentication with RADIUS and EAP for user-level control

Mobile Device Security

  • Deployment models (BYOD, CYOD, COPE) balance security and flexibility
  • MDM/UEM tools essential for managing diverse device fleets
  • Containerization separates work and personal data
  • Full-device encryption critical for lost/stolen device protection
  • Hardening using CIS benchmarks and NSA guidelines
