Course Description

This course introduces the fundamental concepts and practices of cybersecurity, focusing on the core principles of information security including confidentiality, integrity, and availability. Students will explore security controls, threat vectors, vulnerability management, and cryptographic solutions as outlined in CompTIA Security+ certification objectives. The course combines theoretical instruction with hands-on laboratory experiences where students will practice implementing security controls, analyzing security postures, detecting threats, and configuring secure systems in controlled environments. Lab activities include vulnerability scanning, system hardening, encryption implementation, and network security configuration. This integrated approach provides a foundation for understanding enterprise security postures, hybrid environment security, and regulatory compliance within contemporary cybersecurity frameworks.

Place in Curriculum

This course is designed for students pursuing cybersecurity, computer science, or related fields. It helps prepare students for the CompTIA Security+ certification exam and serves as a prerequisite for CYBS 0189 Applied Cybersecurity II.

Course Learning Outcomes

Upon successful completion of this course, students will be able to:

  1. Explain foundational cybersecurity concepts and principles.
  2. Identify and classify various types of security controls.
  3. Analyze common threat actors, vectors, and vulnerabilities.
  4. Apply appropriate cryptographic solutions to security challenges.
  5. Implement basic security architecture principles.
  6. Configure and manage basic security controls.

Tentative Course Schedule

Week 1: Introduction to Cybersecurity and Today’s Security Professional

Lecture Topics: Course overview and introduction, The cybersecurity professional’s role, CIA Triad (Confidentiality, Integrity, Availability), AAA (Authentication, Authorization, and Accounting).

Lab Activities: ACI Skill Labs: Security Concept Fundamentals, OSINT Mini-Lab: The Teapot Trail (bonus module).

Reading Assignment: Security+ Study Guide: Chapter 1 - Today’s Security Professional, CompTIA SY0-701 Objectives: Section 1.2 (Summarize fundamental security concepts).

Week 2: Cybersecurity Threat Landscape

Lecture Topics: The threat landscape and actors, Categories of security controls: Technical, Managerial, Operational, Physical, Control types: Preventive, Deterrent, Detective, Corrective, Compensating, Directive, Threat intelligence and vulnerability concepts.

Lab Activities: ACI Skill Labs: Threat Vectors and Attack Surfaces, ACI Skill Labs: Mitigation Techniques, LEXX: Gathering Site Information, LEXX: Footprinting a Website, Lab Module: Networking Basics.

Reading Assignment: Security+ Study Guide: Chapter 2 - Cybersecurity Threat Landscape, CompTIA SY0-701 Objectives: Section 1.1 (Compare and contrast various types of security controls), CompTIA SY0-701 Objectives: Section 2.1 (Compare and contrast common threat actors and motivations).

Week 3: Malicious Code

Lecture Topics: Types of malware and malicious code, Worms, viruses, Trojans, and ransomware, Indicators of compromise, Change management processes and security implications.

Lab Activities: ACI Skill Labs: Analyze Malicious Activity, LEXX: Examining Spyware, LEXX: Detecting Virtualization, Lab Module: File Integrity & System Calls.

Reading Assignment: Security+ Study Guide: Chapter 3 - Malicious Code, CompTIA SY0-701 Objectives: Section 1.3 (Explain the importance of change management processes), CompTIA SY0-701 Objectives: Section 2.4 (Given a scenario, analyze indicators of malicious activity).

Week 4: Social Engineering and Password Attacks

Lecture Topics: Social engineering techniques and prevention, Phishing, vishing, smishing, and impersonation, Password attack methods, Password security best practices.

Lab Activities: LEXX: Using Anti-Phishing Tools, LEXX: Cracking Passwords, LEXX: Enforcing Password Policies, LEXX: Capturing Credentials via Packet Sniffing, Bonus Module: Supply Chain Risk, Bonus Lab: Malware Analysis.

Reading Assignment: Security+ Study Guide: Chapter 4 - Social Engineering and Password Attacks, CompTIA SY0-701 Objectives: Section 2.2 (Explain common threat vectors and attack surfaces).

Week 5: Security Assessment and Testing

Lecture Topics: Security assessment types and methodologies, Vulnerability scanning and management, Penetration testing concepts, Assessment reporting and remediation.

Lab Activities: ACI Skill Labs: Identifying Security Vulnerabilities, ACI Skill Labs: Vulnerability Management, LEXX: Scanning the Network.

Reading Assignment: Security+ Study Guide: Chapter 5 - Security Assessment and Testing, CompTIA SY0-701 Objectives: Section 4.3 (Explain various activities associated with vulnerability management).

📋 Project Milestone: Security Project Phase 1 Begins

Week 6: Application Security

Lecture Topics: Application security concepts and vulnerabilities, Secure code development principles, Code testing and analysis, Web application security issues.

Lab Activities: LEXX: Performing SQL Injection in DVWA, LEXX: Performing a Reflected XSS Attack, LEXX: Examining Web Application Vulnerabilities, LEXX: Exploiting an Overflow Vulnerability, LEXX: Exploiting a TOCTOU Vulnerability, Bonus Lab: OWASP Top 10.

Reading Assignment: Security+ Study Guide: Chapter 6 - Application Security, CompTIA SY0-701 Objectives: Section 2.3 (Explain various types of vulnerabilities).

Week 7: Cryptography and the PKI

Lecture Topics: Cryptographic concepts and algorithms, Symmetric vs. asymmetric encryption, Public Key Infrastructure (PKI), Digital certificates and signatures.

Lab Activities: ACI Skill Labs: Cryptographic Solutions, LEXX: Using Symmetric Encryption, LEXX: Creating Asymmetric Key Pairs, LEXX: Creating File Hashes, LEXX: Examining PKI Certificates, LEXX: Creating Certificates with OpenSSL, LEXX: Requesting a PKI Certificate in Windows.

Reading Assignment: Security+ Study Guide: Chapter 7 - Cryptography and the PKI, CompTIA SY0-701 Objectives: Section 1.4 (Explain the importance of using appropriate cryptographic solutions).

📋 Project Milestone: Security Project Phase 1 Due

Week 8: Midterm Review and Exam

Lab Activities: Review of selected labs based on student needs.

Reading Assignment: Review of chapters 1-7 in the Security+ Study Guide, CompTIA SY0-701 Objectives: Sections 2.4 and 2.5 (Analyze indicators of malicious activity; Explain mitigation techniques).

🎯 Important: Midterm Exam, proctored in class on Thursday, October 8.

Week 9: Resilience and Physical Security

Lecture Topics: Building resilient infrastructure, Physical security controls and considerations, Business continuity concepts, Backup strategies and disaster recovery.

Lab Activities: ACI Skill Labs: Resilience in Security Architecture, ACI Skill Labs: Data Protection Strategies, LEXX: Scheduling a Server Backup.

Reading Assignment: Security+ Study Guide: Chapter 9 - Resilience and Physical Security, CompTIA SY0-701 Objectives: Section 3.4 (Explain the importance of resilience and recovery in security architecture).

Week 10: Cloud and Virtualization Security

Lecture Topics: Cloud service models and security, Virtualization concepts and risks, Container security, Cloud architecture security considerations.

Lab Activities: ACI Skill Labs: Security Architecture Models.

Reading Assignment: Security+ Study Guide: Chapter 10 - Cloud and Virtualization Security, CompTIA SY0-701 Objectives: Section 3.1 (Compare and contrast security implications of different architecture models).

📋 Project Milestone: Security Project Phase 2 Due

Generative AI and Technology Tools Policy

This course embraces the use of generative Al (such as ChatGPT, Claude, etc.) as valuable productivity and creativity tools. Students are encouraged to explore these technologies as part of their learning experience. To ensure these tools enhance rather than replace learning:

  • Encouraged Uses: Use Al tools to help understand difficult concepts, brainstorm ideas, improve your writing, or create initial drafts that you then refine.
